# SciPlan 科研计划

面向 Windows 个人科研工作的本地任务助手。它把一句随手记录拆成任务，按截止日期和优先级整理，并提供可选的 OpenAI 兼容 AI 助手。

## 下载

直接下载最新版安装包：

**https://github.com/zhongzhuojun/SciPlan/releases/latest**

下载 `SciPlan-Windows.zip` 后解压，双击其中的 `SciPlan.exe` 即可运行，无需安装 Python。

> 程序未做代码签名，首次运行时 Windows 可能弹出 SmartScreen 提示。点击“更多信息” → “仍要运行”即可。

## 启动

直接双击打包目录中的 `SciPlan.exe` 即可。开发版也可以双击 `run.bat`，或在 PowerShell 中运行：

```powershell
python main.py
```

程序优先使用 Windows WebView2 桌面窗口；如果电脑缺少 WebView2，会自动回退到默认浏览器。此版本使用独立的 `%APPDATA%\SciPlan` 数据目录，不会读取旧版 ResearchFlow 数据，也不会写入程序目录。

## 主要功能

- 随手输入一段话，按句切成多个任务
- 规则引擎提取板块、截止日期、耗时，并保护硬截止优先级
- 任务分组：今天必须动、这周安排、本月、等别人回、随时可做
- 快捷调整状态、优先级、截止日期、预估耗时和“我在等”
- 拖动任务到日期栏快速安排时间
- 本地 AI 助手：无 Key 时提供离线建议；填写 OpenAI 兼容接口后可调用模型
- 审稿内容默认不发送到 AI
- JSON 导出与导入
- 可自定义“我的模块”，模块会显示逾期红点
- 首页可添加毕业倒计时、投稿已过去时间和自定义进度卡片
- AI 服务支持多个配置，连接测试通过后再启用和切换
- AI 助手支持每日首次打开问候、连续对话、放大聊天窗口和轻微待机动画
- Windows 桌面版提供独立浮动助手；主窗口最小化或关闭后，助手仍可点击并直接粘贴任务，自动识别后写入主任务库。角色图片单独拖动，输入卡可以正常获得焦点；Ctrl+V、显式“粘贴”按钮和系统剪贴板读取均有兼容处理。右键助手可隐藏，之后可在设置中重新显示。系统托盘菜单可重新打开主窗口或退出驻留。
- 课题全景：课题 → 实验线 → 任务，按剩余工作量和时间压力显示
- 课题详情页：核心目标、当前阻塞、实验线状态、下一个可执行动作
- 课题卡片显示已完成百分比；完成任务后会自动推动主线进度
- 实验线可自由新增并切换状态，默认提供表型线、机制线、写作线和合作线
- 无日期任务支持“时间未知 + 前置条件”，不会因为没有日期而被静默埋掉
- 任务信息完整度提示：目的、判据、依赖、体量和时间状态
- 左侧提供“今天 / 本周 / 全部任务”总览，全部任务中保留已完成记录
- 每条任务都可以打开详情补充备注、分类、课题、实验线、时间、目的和完成判据
- 新任务先进入 AI / 离线分类审核卡片，确认后才写入任务库，分类字段可以逐条改动
- 课题全景卡片支持拖动排序、拖动右侧边缘调整宽度，并提供常驻编辑和永久删除入口

## 可替换助手模块

助手浮层独立在 `ui/assistant_pet.js`，桌面驻留窗口使用 `ui/pet.html` 与 `ui/pet_desktop.js`，图片默认使用 `assets/assistant_character.png`。替换形象时可以直接替换这个 PNG，或修改 `pet_image` 配置；调整点击提示语、拖动行为和动画时只需要修改助手模块，不会影响任务、课题和 AI 对话逻辑。

## AI 设置

在“设置”中添加 AI 服务，填写 Base URL、API Key 和模型名，先点击“测试连接”，再保存并启用。可以保存多个服务并随时切换。Key 仅保存到本机配置文件，并在界面中打码显示。

## 快捷键

- `Ctrl + Alt + Space`：打开快速记录（安装 `keyboard` 后生效）
- `Ctrl + Enter`：提交当前记录
- `Esc`：关闭快速记录

如果未安装可选依赖，程序会自动使用浏览器界面，不影响离线使用。

## Windows 安装包

解压 `SciPlan-Windows.zip` 后双击 `SciPlan.exe` 即可运行；`install.bat` 会把程序复制到 `%LOCALAPPDATA%\SciPlan`，`uninstall.bat` 只移除程序，不删除 `%APPDATA%\SciPlan` 下的数据。
